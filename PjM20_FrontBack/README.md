# PjM20_FrontBack — онлайн-оплата для сайта «Для меня»

Учебный проект в рамках обучения по направлению Project Manager в Школе 21.

## О проекте

Проработана схема подключения онлайн-оплаты для сайта спа-студии «Для меня» (Уфа) через ЮKassa.

## Что проработано

- взаимодействие frontend, backend и платёжной системы;
- формирование платежа на backend;
- передача заказа и суммы на сервер;
- получение ссылки на защищённую страницу оплаты;
- обработка webhook от ЮKassa;
- обновление статуса заказа в базе данных;
- отображение результата оплаты пользователю;
- требования к безопасной обработке платёжных данных.

## Результат

Подготовлена техническая схема полного пути данных: форма заказа → backend → ЮKassa → webhook → статус заказа → уведомление пользователя.
